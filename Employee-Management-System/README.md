# Employee Management System

Spring Boot REST API for the MSE-2 case study, using JDBC (`JdbcTemplate`) and MySQL.

## Requirements
- Java 17+
- Maven 3.6+ (or use the Maven wrapper if added)
- MySQL 8+

## 1. Create the database
Run in MySQL:

```sql
CREATE DATABASE employee_db;
```

The application creates the `employees` table from `src/main/resources/schema.sql`.

## 2. Configure database credentials
Set environment variables before starting the application:

**PowerShell**
```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="your_mysql_password"
$env:DB_URL="jdbc:mysql://localhost:3306/employee_db"
```

Do not commit real database passwords to GitHub.

## 3. Run
From the project root:

```bash
mvn spring-boot:run
```

Base URL: `http://localhost:8080/api/employees`

## API endpoints

| Method | URL | Purpose | Success response |
|---|---|---|---|
| POST | `/api/employees` | Add employee | 201 Created |
| GET | `/api/employees` | Get all employees | 200 OK |
| GET | `/api/employees/{id}` | Get employee by ID | 200 OK; 404 if missing |
| PUT | `/api/employees/{id}` | Update employee | 200 OK; 404 if missing |
| DELETE | `/api/employees/{id}` | Delete employee | 204 No Content; 404 if missing |

### Example POST / PUT JSON
```json
{
  "name": "Aarav Sharma",
  "department": "IT",
  "salary": 45000.00
}
```

## Notes
- The project uses `JdbcTemplate`; it does not use JPA or `JpaRepository`.
- The employee ID is generated by MySQL during insertion.
- Test each endpoint in Postman after starting the application.
